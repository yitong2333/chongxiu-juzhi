# 重修莒志

《重修莒志》是莒县的地方志书，记载了莒县从周武王十有三年至民国二十四年三千余年的历史。

## 目录结构

- [卷首](volume1/README.md) - 序、凡例、题名、目录、图照照片
- [卷一：大事记上](volume1/chapter1.md) - 周、春秋、战国
- [卷二：大事记中](volume1/chapter2.md) - 秦汉至唐宋
- [卷三：大事记下](volume1/chapter3.md) - 元明清至民国

## 关于本书

本志由庄陔兰总纂，于民国二十四年（1935年）完成。全书共七十七卷，分二十册。

> 志之总例有四：一曰图，二曰记，三曰表，四曰志。

## 编辑团队

- **总纂**：庄陔兰
- **发起**：县长唐介仁
- **筹备**：李艳、张晋阶、魏延琴等
- **绘图**：何锡朋
