## 重修宫志序

昔本古国，其幅员殆较今县境为狭。秦以后为郡为县为州而复为县，疆域界划亦多存疑。其与图山水建置经制文物之散见群籍者，十无二三。此宋贤创作方志，论者谓有裨国史，守土之吏当视为急务者。况世变日新，关系政教愈切，而复值旧闻放失之后乎。

昔志自胜清嘉庆间，邑令许氏绍锦续修，迄今又百余年，中经张氏承燮、蒋氏楷，及邑绅管氏廷献等先后倡修。张氏仅创体例，将篇属稿未就，旋复阁置。前任宿松唐君剑青徇各区区长之请，呈准省府，规划未就，而唐君去职。

民国二十二年十二月，少泉奉令代理下车，伊始邑人士复以为言。余曰：「此吾责也。」乃延邑耆宿庄心如太史董其成，复聘李君炳南、周君召亭、庄君德符、赵君阿南，分襄厥事。

二十三年三月开局编纂，值匪患方殷，县城书闭，而诸君子操觚不辍，罔间昕夕。星霜再历，成书凡七十七卷，都二十册。

少泉昔负笈燕市时，研政籍，浏览方志，种类浩繁，不可悉读。识陋所知，搜辑之富，殆罕与此书比伦。

昔万季野论修史，宜尚详实，谓所著明代史纂繁无倍于宋史，且非不知简之为贵，恐后之人务博而不知所裁，故先为之极，使知吾所取者有可损，而所不取者必非其事与言之真而不可益也。

今之志书，有关地方政教，为后来考镜之资，尤重于史。得兹巨制，纲罗参伍，融贯新旧，举全邑之舆图山水、建置经制、文物，一一纪实，以待后之治国闻者要删。

马盖与万氏论史之旨，先后同符。视康对山《武功志》以简胜，洪北江《登封志》以拟古胜，陆祁孙《续郡城志》以修辞胜者，其用意固不侔矣。

少泉治邑二载，愧乏政绩，念昔人爱余之殷，依依不忍去。惟冀世变少戢，归耕故里，楼迟莲池之侧，徜徉濯水之上，重披此编，宛如浮来朝爽、沐水清流、毗卢古阁、望诸故垒，历历在目。更难忘干戈扰攘之际，诸君子风雨一灯，商订义例时也。

河北清苑卢少泉序。

## 重修宫志序

方志者，具有时代性者也。修现代之方志，必具现代之眼光，应现代之需要。所有纂述详略之间，自宜深切注意，未容率尔从事也。

吾国在昔，省有省志，府有府志，县有县志，甚至乡有乡志，里有里志。方志之作亦云盛矣，而其囊括一乡一里之志，成为一代文献；上备省志之采择，下作行政之标准者，厥惟一县之志。然则县志顾不重哉？

昔志始自明成化，迄于清嘉庆，中间虽屡经修辑，而其内容所载，大抵沿袭旧例，无大变动，殆亦时代使然欤。

民国二十二年冬，省令各县修志。其明年，卢前县长少泉聘请邑绅庄心如先生任总纂。二十四年年终，编辑蒇事，校印未竣而解职以去。本年六月，余承乏斯邑，履政之初，虽因簿书鞅掌，缉捕劳形，未遑过问志乘之事，然窃以为昔古国也，亦饶邑也。自周初至今三千有余岁，其间因革损益，古今异宜，固不待言。即以民国二十余年而论，世事日趋复杂，所有政治之改进、社会之震荡、物产经济之消长、农工商业务之盈虚，日新月异，而岁不同，必不能一一悉如古所云。

当斯时而言修志，倘无现代之眼光、博通之学识，斟古酌今，循名核实，以求适当，则书成而后，或于现代潮流之动向、经济文化之发展，容有未合，将何以信今而传后也？

故修现代之县志，其事倍难于往昔。今赖庄先生等之力，全志告成。志之总例有四：日图、日记、日表、日志，而以子目分类相属。所详者或甄录前志，或增补阙遗或加之以考证，或附之以名著。凡所纂述，要皆以纪实为指归。所略者，大都无关世道人心、国计民生之记载，而又博考典礼，广搜金石碑版，以补前志之缺。庄先生等之用心，可谓精且勤矣。

披览一过，虽不敢谓尽合现代之需要，而其综括古今、足备将来征文献者之采择，则所敢断言也是。

中华民国二十五年十一月  
献县牛介眉

## 叙例

自来方志之作，多在国家统一之世，而赓续于承平日久、文物大备之时。莒志昉自成化，续于万历，中更崇祯壬午之变，毁灭无存。清顺治五年，乃重修焉。然今存者，康熙、雍正、嘉庆三志而已。

康熙志成于敕修一统志时，盖自顺治间重修，至康熙十一年，知州张文范任内，乃告成书。雍正志李氏方膺稿本，就于雍正十一年至乾隆七年，乃付剞劂。惟嘉庆志成于许氏绍锦之一手。时当嘉庆元年，清运盛极而衰征已见，教匪作矣，道光始有夷祸，咸丰几于失国，同光继续，天下粗安，其间州牧之通晓文事者，如蒋氏楷、张氏承燮，皆有续修莒志之举；地方士绅，则管氏廷献等，且有手订稿本，然卒未成书。盖至是而莒志之失修者已百余年。

民国十五年，邑人复议重修，延单氏锐主其事，中更兵乱，属稿未完。二十二年冬，十区区长傅心如等，合辞上请县府，乃有重修莒志之筹备委员会等分任编纂。二十三年二月，始设局采访，而刘桂堂窜扰山东，遂及莒县，逮兵事结束，人心大定，至夏秋间，乃渐见访稿。爰取康、雍、嘉三志，及周氏兴南《莒志述遗》——录自蒋、管各稿，复有增补，类次别择，补其未备——自周武王十有三年，至于民国二十四年，三千余年之事，裒为一编，故不系以州县之名，而概曰《莒志》云。

志之总例有四：一曰图。图之数二十有二，自全县疆域，以及旧志之州治学宫，无弗详焉，仿张氏《图经》例也。二曰记，自春秋莒国以——

及民国之事，撮其大要而为全志之纲领者也。三曰表。记所弗能详者，则以表列，故表次乎记。表之总目凡四：曰沿革，曰职官，曰封爵，曰选举。依蒋氏例也，而分属于各志者不与焉。四曰志。凡记与表所弗详，至于志则无弗详矣。

志之最关重要者，厥惟舆地。凡星度、气候、地质、里至、山脉、水系、建置、物产，皆隶之。此与图相为表里，而非图所能该也。革命成功，党治开始，列于经制之先，所以重党务也。经制首县政，若财政，若教育，皆县政之大者；军备攸关治乱，司法以制奸宄，此尤经制要政，不可以弗著也。

民社一志，前志所无，仿胶志例增，所以重民治也。地方自治，实握民治之枢；农、工、商业，又为自治之本。他如宗教、氏族、风俗，孰非理民社者所当维持整顿者哉？

民国献县志以文献统人物，兹略仿其例，首列典礼，次及坛庙之载在祀典者，附以祠庙寺观，著其兴废之迹，亦可以观世变矣。复次古迹、金石、艺文，后之览者，傥亦有据怀旧之蓄念、发思古之幽情者乎？

旧志稿张氏序例，引外史掌四方之志，自公卿诸侯至于群士善恶之迹，毕集史职。此志人物者所由昉也。然方志之体，究异史裁，善善从长，贬恶则僇。故世家、宦迹以及各列传，著其懿行，而略其纰谬，使贤者有所法，不肖者反而省，其与激扬之旨，或无舛乎。

旧志之纪列女略矣，今志列女较前志增数倍，以采访配偶者惟此最多，而于穷乡寒门、未经旌表者，犹恐遗漏焉。其有事迹见之记载者，无弗登焉，非滥也。盖自政府更定褒扬条例——

独标孝义，而贞节之名乃不见于旌典矣。然莒人素重廉耻，尤崇妇节。千百年来，矢柏舟而效历年者，寖以成俗，且其人死者已矣，生者夙称未亡人矣，及今有遗于后，安述过而存之，非敢与孝义之条有所刺谬也。

若夫前人著述有关莒故，仿章氏文征例，分属各类；其他遗篇零什，蒐辑无多，姑附艺文书目后。其杂缀轶闻，无关宏旨，列诸志余。张氏外编《莒征莒览》之作，请俟异日。

前志义例，莫详赡于张氏。然张氏议修志时，并未见康熙志，今借自北关刘氏，惜卷首不完，无可校补。雍正志庶有存者，亦有缺简。兹录二志序例篇目及各小序，存其梗概。嘉庆志今印之本，列女传亦缺三十余页，已借旧本钞补，原版尚存县署。兹存其序例暨编纂姓氏，余从略焉。

蒋稿目录录自《述遗》，张稿序例及目录依旧钞本。其余有关前志之文字，悉加甄录，而以单稿所著序引各篇附焉，别为一卷。诸城张栋铭、李骥氏寄赠《莒志考证》，援引博辨，裨益宏多，已备录其说于沿革表及古迹之后，附识于此。

莒自春秋以来，以国名县，至今无改，与他县异；则其为志，当与他志异。至民国而为莒志，又当与前志异。然综是数异，而有一同焉：曰纪实而已矣。实为国矣，则志乎国；实为郡而州而县矣，则志乎郡与州县。谓旧志宜略，而实则详焉，夫安得而略；谓新志宜详，而实则略焉，夫安得而详。新与旧杂陈，而古与今间出；详与略异宜，而因与革互见。编年则国非一体，断代则事仍相承。譬之一身端——

冕补服而革履也，譬之一简篆籀隶楷而国音字母也，稽于古无成例，实即其例也；创于今无定体，实即其体也。

虽然，吾有惧焉。当十九世纪之末、民二十余年之间，而谈志乘，必详著乎政治之演进、社会之嬗变，以究极夫治乱得失之所在。吾诚无能为役，若惟是窥窃陈编，涂饰耳目，曰吾秉经也、酌史也、仿古名著也，未知其与纪实之旨果有合焉否也。

夫山川不能语，而古人不可作。吾述古而不实，古人乌得而质之；若征今而不实，人皆得正其失而纠其谬矣。吾为此惧，尚望海内宏达，进而教之。

中华民国二十四年十二月
庄陔兰谨识
